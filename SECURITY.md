# Security reports

Sapera parses untrusted game-image files. If you find a way to overwrite an input, escape the requested output directory, bypass exact-build checking, or make an invalid patch look verified, that's something I want to hear about.

Please avoid publicly posting a working exploit before there's been a chance to fix it. GitHub's private security-advisory feature is preferred when available. Otherwise, contact the maintainer through the repository profile.

Don't attach private cabinet identity data, complete ROM/CHD images, timekeeper dumps or proprietary game code to a report. A minimal synthetic test case is better anyway.

There are no guarantees that experimental recovery profiles are safe for original equipment. Back up your own media before testing, and use separate output copies.
